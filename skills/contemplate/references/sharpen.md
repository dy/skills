# Sharpen any question

Source: [dy/contemplation](https://github.com/dy/contemplation) `questions-enhancement.md`.
Every flat question sharpens by moving along an axis. Apply to each selected question until
it points at THIS artifact — a name, a file, a number, a moment. Flat question = flat answer.

## The moves

**1. ZOOM** — in: concrete, atomic («What's the problem?» → «Show me one person's exact
pain — the precise moment it hurts»); out: pattern, category («What's the feature?» →
«What category does this create? What job is it hired for?»).

**2. FLIP** — opposite («How do we succeed?» → «How do we definitely fail?»); remove
(«What's valuable?» → «If we deleted half — which half lives?»).

**3. SHIFT** — time («Is this good?» → «Will this embarrass in 6 months?»; «Will this
work?» → «It's six months later and it failed — what killed it?»); perspective («What's the
UX?» → «What would my harshest critic see in 5 seconds?»; «Is this choice right?» → «What
would the best expert in this field do instead — and why would they reject mine?»);
constraint («What should we build?» → «What would we ship with one day?»).

**4. GROUND** — abstract to concrete: names, numbers, moments («What's the goal?» →
«What does victory taste like? What ONE number defines it?»; «Who's the user?» → «One
person. Name them. What's their curse?»).

**5. FEEL** — emotion as signal («What should we prioritize?» → «What excites? What
drains?»; «What's blocking?» → «What am I pretending not to know?»). Excitement = signal.
Drain = poison. Avoidance = the thing.

**6. RECEIVE** — the question acting on you, not you on it: «What question keeps
returning no matter how many times I dismiss it?», «What is this situation asking ME?»,
«What's trying to be born that I'm blocking?». Use this to pick the final "yours to
answer" set — return the questions that kept surfacing during the session.

## Master question per axis

| Axis | Master question |
|---|---|
| Direction | What's another way to ask this? |
| Time | When does this matter? |
| Scale | At what level does this live? |
| Perspective | Who else should answer this? |
| Constraint | What if the rules changed? |
| Abstraction | Is this too vague or too specific? |
| Emotion | How does this make me feel? |
| Negation | What if the opposite were true? |
| Meta | What question am I actually trying to answer? |

## Sharpening in this skill's context

When sharpening an **[ask]** question for the final section, bind it to evidence found
during the session: not «What am I afraid to ship?» but «The demo in `example/` works and
tests pass — what stops you publishing v1 today: the missing docs, or that it might be
ignored?». The sharpened question should be impossible to answer with a platitude.
